# Vitalis IMC

Aplicação web em **Flask** que calcula o IMC e oferece uma análise educativa personalizada, com explicação de possíveis riscos associados ao peso e sugestões de exercícios conforme o objetivo do usuário.

🔗 **Acesse o projeto online:** [https://projectimc.vercel.app/](https://projectimc.vercel.app/)

## Assistente inteligente

O projeto possui um assistente baseado em regras que considera:

- IMC calculado
- Idade informada
- Objetivo: saúde geral, perder peso ou ganhar massa muscular

A partir desses dados, ele gera:

- Uma explicação sobre a faixa de IMC
- Possíveis pontos de atenção relacionados ao peso
- Sugestões de exercícios e frequência semanal
- Orientações educativas adaptadas ao objetivo escolhido

O IMC é uma medida inicial e não considera diretamente massa muscular, gordura corporal, distribuição de gordura, sexo ou condições de saúde individuais.
